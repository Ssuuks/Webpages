# 숫자부대 돌격

광고에서만 보던 "게이트 고르기 + 좀비 떼 + 보스" 게임을 실제로 할 수 있게 만든 모바일 웹게임. 서버·빌드 없이 GitHub Pages에서 돈다.

- 주소: `https://ssuuks.github.io/Webpages/squad/` (main에 반영된 뒤)
- 조작: 화면 **왼쪽·오른쪽을 꾹 누르면** 그쪽으로 이동. 손가락을 옆으로 끌면 끄는 만큼 따라온다. 영웅 스킬은 화면 아래 가운데 둥근 버튼(게이지가 다 차면 통통 튄다). 키보드는 ←/→(A/D), 스킬은 Space/↑/W, 일시정지는 Esc/P.
- 진행은 기기(localStorage)에만 저장된다. 사생활 보호 모드처럼 저장이 막혀도 게임은 돈다(그 판 동안만 기억).
- 판 도중에 나가도(탭 닫기·전화) 3초마다 저장해 두어 **이어하기**로 그 자리부터 계속한다.
- 설정 → 데이터에서 **백업 코드**(`SQD1.`로 시작하는 글자)를 만들고, 다른 기기에서 붙여 넣어 진행을 옮긴다. 가져오기 직전 상태는 한 번 되돌릴 수 있다.

## 규칙

- 분대는 자동으로 전진하며 앞으로 계속 쏜다. **서 있는 위치가 곧 조준**이다.
- 게이트: 분대 중심이 지나가는 칸 하나만 적용. `+a` `−a` `×2` `×3` `÷2`(올림이라 0이 되지 않음). 결과가 0 이하이면 전멸.
- 덧셈 게이트는 총알을 받는다. 일정 피해마다 숫자가 1씩 오른다(빨강 → 회색 → 파랑). 곱셈·나눗셈 게이트는 총알이 통과한다.
- 부딪힘: 적·바리케이드는 **남은 체력 10마다 병사 1명**을 잃게 한다. 미리 깎을수록 덜 잃는다.
- 상자: 쏴서 부수면 무기 강화(그 판 동안, 최대 3단계)·지원병·코인. 부수지 못하고 지나가면 그냥 깨진다.
- 독침 좀비는 분대가 지나갈 자리에 초록 표시를 남기고 1초 뒤 터진다. 톱날은 레일 위를 오가며 겹친 동안 병사를 잃게 한다.
- 보스: 마지막 경기장에서 분대가 멈추고 보스가 걸어온다(화면에 닿기까지 남은 초). 빨간 구역(내려찍기, 맞으면 병력의 25%)을 피하며 쏜다 — 보스는 분대를 천천히 따라오고 몸 가운데만 총알이 맞아서, 피하면 그만큼 덜 쏜다. 내려찍기는 대개 분대가 선 칸을 노린다. 보스가 분대에 닿으면 계속 짓밟는다(짓밟힌 병사는 되살아나지 않는다). 체력이 절반 아래면 빨라진다. L3부터 졸개를 부른다.
- 별: 이기면 ★, 기준 병력(별 기준)의 45% 이상 남기면 ★★, 90% 이상이면 ★★★. 별 기준은 그 플레이어의 강화·출격 영웅을 단 기준 봇이 스킬 없이 남기는 병력이다.
- 강화(코인): 시작 병력 +2명, 화력 +5%, 보급(코인) +10%. 단계마다 값이 1.5배. 새로 살 수 있는 단계는 진행에 따라 열린다(그 진행의 기대 강화 + 1 — 이미 산 단계는 그대로).
- 레벨 태그: 5레벨마다 **어려움**(코인 ×1.5), 10레벨마다 **매우 어려움**(×2), 그 다음 레벨은 **쉼**. 어려운 레벨은 짧고(L15부터), 상자·철창을 챙겨야 수월할 수 있다. 일반 레벨은 상자·특수병 없이도 깬다.
- 같은 레벨에서 3번 연속 지면 지원 병력을 받고 다시 할 수 있다(그 판은 별 최대 1개). 지원 크기는 레벨마다 보정해 둔 값(`lv.helpStart`)이다.

## 특수병과

판 안에서만 얻는다. 철창(L5~, 쏴서 열면 합류)과 금색 게이트(L9~, 병사가 조금 덜 느는 대신 특수병이 합류)로 들어오고, 분대에 최대 3명·병과마다 1명. 특수병 1명마다 일반 병사가 4명은 있어야 버티며, 한 번에 크게 맞으면(병력의 15% 이상이면서 3명 이상, 또는 보스 내려찍기) 가장 늦게 온 특수병이 쓰러진다. 판을 끝까지 함께하면 1명당 코인 +3.

| 병과 | 열림 | 하는 일 |
|---|---|---|
| 의무병 | L5 | 게이트가 아닌 곳에서 잃은 병사의 60%를 몇 초 뒤 되살린다 |
| 저격수 | L9 | 1.2초마다 독침 좀비·거구부터 저격, 보스전에서는 보스 |
| 로켓병 | L13 | 2.4초마다 가장 큰 무리나 앞을 막은 벽에 범위 로켓 |

보스전에서 특수병과·영웅(뭉치 스킬로 늘어난 총알 포함)이 더하는 피해는 일반 병사 화력의 10%까지만 센다(보스가 너무 빨리 녹지 않게, 스킬을 안 누르는 사람과 차이가 너무 벌어지지 않게).

## 영웅

한 판에 한 명 데리고 나간다. 합류는 진행 조건으로 무료, 레벨(1~5)은 코인으로 올린다(150·300·500·800). 레벨 상한은 진행에 따라 열린다(L1~10은 Lv2, 10레벨마다 +1). 스킬 게이지는 시간·처치로 차고, 다 차면 버튼이 통통 튄다. 설정에서 '스킬 자동 사용'을 켜면 알아서 쓴다(기본 꺼짐).

| 영웅 | 합류 | 상시 효과 | 스킬 |
|---|---|---|---|
| 뭉치 대장 | L2 클리어 | 덧셈 게이트 올리는 속도 ×1.1~1.25 | 돌격 나팔: 5초 동안 총알 피해 ×1.25~1.4 |
| 보리(의무) | L8 클리어 | 잃은 병사의 12~30%가 천천히 돌아옴 | 괜찮아 주사: 방금 잃은 병사 50~70% 즉시 회복, 잠깐 손실 크게 감소 |
| 나비(저격) | 별 30개 | 1.8초마다 직접 저격, 레벨마다 보스전 추가 피해 한도 +2%p | 백발백묘: 3초 동안 강한 적 12발 연속 저격 |

영웅을 데리고 가만히 있기만 해서는 이기지 못하게 맞춰 두었다(테스트로 확인).

## 레벨과 밸런스

레벨은 레벨 번호로만 정해진다(모두에게 같은 배치). `assets/core.js`의 생성기가 청크(게이트 줄, 좀비 무리, 바리케이드, 상자, 독침, 톱날, 쉼)를 이어 붙이고, 그동안의 "무난한 병력"을 추정해 게이트 숫자와 적 체력을 정한다. 메커닉은 레벨마다 하나씩 처음 소개된다(L2 ×2·마이너스 게이트, L3 바리케이드, L4 상자·질주 좀비, L5 독침, L6 톱날, L7 거구, L8 ÷2, L10 세 갈래).

보정은 그 레벨에서 사람들이 **실제로 들고 오는 힘**을 기준으로 한다(SIM 5).

- **기대 강화(EXPECT)**: 사람 흉내 봇(0.3초 늦은 반응, 10% 실수)이 L1부터 코인으로 가장 싼 강화·영웅 레벨을 사며 돈 캠페인 8개의 레벨별 첫 시도 중앙값. 보정과 서로 물리므로 두 번 되풀이해 굳혀 표에 적는다. 판 중 위협(적·벽·상자·철창 체력, 덧셈 칸 오르는 속도)도 EXPECT 시작 병력·화력으로 출발한 골든 패스로 정한다.
- **일반·쉼·첫 레벨(L1~4)**: 보스 체력 = 기준 병력이 정면에서 `bossKill`초 동안 주는 피해 × m(L1~4 0.9, L5~10 0.88, L11+ 0.9, 쉼 0.68). 기준 병력은 EXPECT를 단 기준 봇(스킬 끔)의 도착 병력. 상자·특수병 없이 기준 병력으로 이길 수 있는지 확인하고, 못 이기면 낮춘다.
- **어려움·매우 어려움**: 사람 흉내 봇 무리(집중한 사람 스킬 씀·안 씀, 산만한 사람 — 종류마다 24판)를 경기장까지 돌려 각자 이길 수 있는 가장 큰 보스 체력을 잰 뒤, 무리의 첫 시도 승률이 태그의 목표 구간(`BOSS_SPEC.band`)에 가장 가깝게 되는 체력을 고른다. 단 기준 봇(EXPECT + 영웅, 스킬 자동, 상자·특수병 씀)이 도착 병력의 10%를 남기고 이기는 체력(H*)을 넘지 않는다.
- **배치 검사**: 판 내내 한 자리(x = −4.4, −2.5, 0, 2.5, 4.4)에 서 있는 분대가 기대 강화로도, 그 진행에서 살 수 있는 최대 강화로도 이기면 그 배치는 쓰지 않는다(보스를 조금 세게 해 보고, 안 되면 다른 배치로). L1(튜토리얼)과 L2~4는 예외다(아래).
- 3패 지원 병력(`helpStart`)은 '약한 기준'의 도착 병력이 태그별 비율(일반 60%, 쉼 25%, 어려움 150%, 매우 어려움 70%)만큼 늘어나는 수다 — 산만한 사람도 지원 판을 대부분(85~95%) 이기지만 늘 이기지는 않게 맞췄다.

L1~120은 이 결과를 미리 계산한 표(`assets/caltable.js`)를 읽어 레벨이 바로 시작된다. 그 뒤 레벨은 처음 열 때 계산한다(어려운 레벨은 H* × 표의 같은 태그 레벨들의 '체력/H*' 중앙값, 배치 검사는 기대 강화로 세 자리만 — 4코어 PC에서 레벨당 평균 0.2초, 길어야 0.5초). 시뮬레이션 규칙을 바꾸면 `core.js`의 `SIM`을 올리고 표를 다시 만든다(옛 표는 `SIM`이 달라 자동으로 무시된다).

```sh
node squad/tools/caltable.mjs                 # EXPECT 두 번 되풀이 + L1~120 보정: 4코어에서 3분쯤
node squad/tools/caltable.mjs --iters 0       # 상수만 바꿨을 때: 지금 EXPECT로 보정만 다시(1분쯤)
```

## 파일

- `index.html` — 화면 뼈대와 스타일(메뉴·HUD·스킬 버튼)
- `assets/core.js` — 시뮬레이션(DOM 없음): 레벨 생성, 고정 틱 갱신, 특수병과·영웅, 봇, 보정, 별·코인, 판 저장용 스냅숏
- `assets/roster.js` — 영웅·특수병과 이름·소개·수치, 지역
- `assets/caltable.js` — L1~120 보정 표와 EXPECT 표(생성물, `tools/caltable.mjs`)
- `assets/render.js`, `view.js`, `pix/` — 도트 렌더링, 카메라, 스프라이트(이미지 파일 없이 코드로 찍는다)
- `assets/main.js` — 루프, 조작, 화면 흐름, 안내, 이어하기
- `assets/audio.js`, `music.js` — WebAudio 합성 효과음, 8비트 배경 음악
- `assets/store.js` — 진행 저장(v2), 강화 표, 되돌리기용 보관
- `assets/save.js` — 진행 중인 판 저장, 백업 코드 만들기·읽기
- `sw.js` — 오프라인 캐시
- `DESIGN.md` — v2 기획과 시뮬레이션→렌더러 약속
- `tests/bots.mjs` — 측정용 봇 묶음(기준·숙련·사람 흉내·오판·꼼수 봇), 테스트와 측정 도구가 함께 쓴다
- `tools/` — 보정 표 만들기(`caltable.mjs`), 난이도 측정(`bench.mjs`·`benchlib.mjs`, 실험 `margin.mjs`·`fork.mjs`·`fbcal.mjs`), 기준선 `bench-baseline.json`

## 테스트

```sh
node --test squad/tests/run.mjs    # 4코어에서 1분쯤(무거운 봇 묶음은 워커로 나눠 돈다)
node --test squad/tests/art.mjs
```

게이트 계산, 레벨 생성 규칙(L1~60), 결정성(같은 입력 → 같은 상태 해시), 특수병과·영웅 규칙, 판 저장 왕복, 저장 이전(v1→v2), 백업 코드, 오프라인 캐시 목록, 화면이 쓰는 내보내기(`levelTag`·`upgCap`·`bossEta`·`supportFor`·gate 이벤트의 `alt`), 보정 표가 최신인지를 본다. 난이도는 개선 계획(difficulty_targets 1단계)의 구간으로 본다.

- 기준 봇은 EXPECT로 L1~126을 모두 깨고 보정 실패가 없으며, 별 기준(par)은 기준 봇이 실제로 남기는 수와 같다.
- 태그×구간 묶음(묶음마다 48판 이상, `tools/bench.mjs`와 같은 시드): expert / 집중한 사람(sloppy0.1) / 스킬 안 누르는 사람(하한 −10%p) / 산만한 사람(sloppy0.3)의 첫 시도 승률, 이긴 판의 별 비율, 판 길이. 표본이 작아 구간 끝에서 5%p까지는 본다.
- 꼼수 상한(기대 강화와 살 수 있는 최대 강화 둘 다): 가만히 ≤5%, 마구 ≤10%, 고정 위치 5곳 각각 ≤15%(L1~4 ≤30%), 늘 최악 칸 ≤20%(L11+; L1~10 ≤50%), 숫자만 보기 일반 ≤70%·어려움 ≤40%. 배치 검사를 못 넘은 레벨만 서 있기로 이길 수 있다.
- 지원 받은 산만한 사람의 승률 85~95%, 표 밖 레벨(L121+) 보정 시간.
- 1단계로 못 맞춘 목표는 `todo`로 남긴다(이유는 아래 '알려진 차이').

브라우저에서 확인할 때는 콘솔에서 `__squad.auto = true`로 봇이 대신 플레이하게 할 수 있다.

### 난이도 측정(오프라인)

```sh
node squad/tools/bench.mjs                      # L1~60 전부: 4코어에서 2분쯤
node squad/tools/bench.mjs --levels 11-20 --seeds 4 --brief --compare squad/tools/bench-baseline.json
node squad/tools/bench.mjs --expect-only --levels 1-120 --json expect.json
```

봇(`tests/bots.mjs`)을 레벨마다 세 조건 — 강화 없음, 기대 강화(EXPECT: 사람 흉내 봇이 코인으로 가장 싼 강화·영웅 레벨을 사며 L1부터 돈 캠페인의 레벨별 중앙값), 살 수 있는 최대 강화(꼼수 봇만) — 으로 돌려 구간(L1-4, 5-10, 11-20, 21-30, 31-40, 41-60)·태그별 첫 시도 승률, 도착 병력/기준, 보스 접촉, 내려찍기 적중, 패배 시점, 최고 병력으로 끝난 판, 별 비율을 찍는다. 캠페인에서는 지원 사용률, 시도 수(p90), 최종 통과율을 본다. 마지막에 개선 계획의 목표 구간과 맞는지 표시한다. `tools/bench-baseline.json`은 SIM 4 규칙(옛 게임)에서 잰 기준선, `tools/bench-phase1.json`은 1단계(SIM 5) 결과다.

알려진 차이(1단계로는 못 맞춘 것 — 2단계 '판 중 긴장'에서 다룬다):

- **매우 어려움 L20+의 expert 승률**(목표 65~85%): expert는 기준 봇과 같은 판단이라 기준 봇이 이기는 체력 아래에서는 거의 늘 이긴다. 사람 숙련자 플레이테스트로 확인할 것.
- **L10의 스킬 차이**: 영웅 Lv1로 70초 판을 돌면 스킬이 보스를 잡는 힘의 약 20%를 차지해, 스킬 쓰는 사람의 구간(55~70%)과 안 쓰는 사람의 하한(45%)을 한 체력으로 둘 다 맞출 수 없다. 보정은 그 사이를 고른다.
- **L2~4의 고정 위치, L1~10의 '늘 최악 칸'**: 첫 레벨들은 한 자리에서 계속 쏘아 올리기만 해도(나쁜 칸도 메워진다) 기준 병력만큼 모여, 산만한 사람이 90% 이기는 보스로는 가를 수 없다 — 판돈 줄(P07)이 필요하다.
- 판 중 지표(오판 봇과의 차이, 도착 병력/기준, 보스 접촉, 내려찍기 적중, 경기장 전 패배, 낙폭, 최고 병력으로 끝난 판)는 2단계 목표다.

같은 틀을 쓰는 실험 도구: `margin.mjs`(보스 체력·접촉 시간 격자), `fork.mjs`(한 줄만 가장 나쁜 칸으로 갔을 때 승→패로 뒤집히는 줄), `fbcal.mjs`(기준 봇이 겨우 이기는 보스 체력 H*와 여유).
