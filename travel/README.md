# 가족 여행 플래너

여러 여행을 계획·관리하는 모바일 웹앱. GitHub Pages에서 도는 정적 앱이고 서버가 없다.
나트랑 단일 페이지 앱(`../nhatrang.html`)을 일반화했다. **엔진(이 폴더)과 데이터(여행마다 JSON 하나)를 분리**해서, 여행이 바뀌어도 코드는 고치지 않는다.

- 주소: `https://ssuuks.github.io/Webpages/travel/` (main에 반영된 뒤)
- 데이터: 비공개 저장소 `travel-data`를 사용자 토큰으로 읽고 쓴다. 토큰이 없으면 기기(IndexedDB)에만 저장된다.
- **이 공개 저장소에는 여행 데이터를 넣지 않는다.** 데모(`samples/demo.json`)만 있다.

## 처음 설정

1. GitHub에서 **비공개** 저장소 `travel-data`를 만든다(README로 초기화).
2. Fine-grained 토큰: Repository access는 `travel-data`만, Permissions → Contents: Read and write, 만료 90일.
3. 앱 [설정]에 토큰을 넣고 [저장하고 확인]. "비공개, 쓰기 가능"이 나오면 된다.
4. 홈 [가져오기]에 여행 묶음 파일(`travel-data-bundle.json`)을 넣고 [검사] → [저장] → [모두 커밋].
   저장소에 `trips/index.json`, `trips/{id}.json`, `datasets/{id}.json`이 만들어진다.
5. 다른 기기(배우자 폰): [설정 → 다른 기기 연결 → 연결 코드 만들기]로 저장소·토큰·비밀값·가족 프로필을 코드 하나로 옮긴다(암호를 정하면 암호화). 받는 쪽은 홈의 [다른 기기의 연결 코드 붙여넣기].
6. 아이폰은 사파리 공유 버튼 → [홈 화면에 추가]해서 쓴다. 사파리에서만 쓰면 오래 안 열었을 때 기기 저장소가 지워질 수 있다.

## 화면

- 홈: 진행 중 → 다가오는 여행(D-day) → 지난 여행. [새 여행] [가져오기] [동기화].
- 여행 안 탭: **오늘 · 일정 · 장소 · 준비 · 비상 · 더보기**(예약 · 패스 · 경비 · 지도 · 메모 · 서류함 · 공유·인쇄 · 데이터).
  - 오늘(여행 중): 시간별 강수확률·돌풍, 지금/다음 일정과 남은 시간·거리·출발 시각, [늦어졌어요 +15/+30/+60분](이후 일정을 한꺼번에 밀고 경고 다시 계산, 항공·교통에 묶인 일정은 그대로), [오늘 가볍게](선택 일정 숨김), 다음 일정 [건너뛰기]·[대안 찾기], 빈 시간 1시간 이상이면 가까운 곳 추천(지금 열려 있고, 아이 추천·찜·쓸 수 있는 패스 장소 먼저), 오늘 할 일(공항 도착 목표와 출발 시각, 렌터카 반납 준비), 오늘 필요한 서류·비밀값, 강풍 경고, 지출 기록·환율 계산, 오늘의 한 줄. 해외 여행이면 현지·한국 시각을 함께.
  - 오늘(여행 전): D-day, 마감 다가오는 준비와 자동 알림, 열린 질문, 일정 점검, 출발일 날씨·바람.
  - 일정: 날짜 탭, 세로 타임라인, 날짜마다 요약 한 줄(고정 외출·선택·운전 합계·패스), 이동 구간(km·분), 패스 도장, 선택·잠정 배지, 점검 경고(가족 규칙 포함), 항공편 날 강풍 경고, 안 전환(기본·우천 등), 편집 모드(추가·삭제·순서), 날짜별 '수정됨'과 [이 날 되돌리기], 여행 중·후에는 일정마다 [완료]·[건너뛰기]와 그날의 한 줄 기록.
  - 장소: 분류·배지·'지금 운영 중' 필터, 지역별/가까운 순, 기준점(오늘 숙소·특정 숙소·다음 일정 장소·현재 위치), 장소 시트(카카오·네이버·구글 길찾기, 전화, 운영시간, 패스 혜택), 찜, 일정에 넣기, 구글 지도 링크로 추가, AI로 여러 곳 추가. 데이터셋 장소(예: 제주투어패스 94곳)도 함께 보이고 일정에 넣으면 여행 장소로 복사된다.
  - 준비: 가족의 여행 첫날 기준 나이·개월(기기 프로필의 생년월일로 계산), 마감 순 목록, **자동 알림**(예약 오픈: 일정에 넣은 장소의 "바코드 7일 전"·"24시간 전" 같은 조건이나 '예약 필요' 배지 / 항공 온라인 체크인(출발 24시간 전) / 공항 도착 목표(국내 60분·해외 150분 전) / 렌터카 반납 준비(종료 2시간 전) / 레이트 체크아웃 요청(멤버십에 '레이트'가 있으면). 손으로 적은 체크리스트와 겹치면 숨기고, [체크리스트에]로 옮길 수 있다), 다른 여행의 체크리스트 불러오기(마감일은 출발일 차이만큼 이동).
  - 예약: 숙소·교통 직접 추가·수정·삭제, 비밀값 키 지정, 연결된 서류, 항공편 운항 정보 링크.
  - 패스: 첫 입장·이용 기록과 만료·다음 입장 가능 시각, 가까운 패스 장소, **패스 손익**(계획한 패스 일정의 우리 가족 정가 − 추가금 − 패스값. 장소의 `prices`·`pass.surchargePrices`가 있어야 계산되고, 모르는 곳은 [가격 조사 프롬프트]로 채운다).
  - 서류함: 바우처·패스 QR·탑승권 캡처. 파일은 비공개 저장소 `docs/{여행id}/`에 올리고 기기에도 사본을 둬서 오프라인에서 열린다. 목록은 여행 JSON의 `documents`. [모두 이 기기에 받기]로 출발 전에 받아 둔다.
  - 공유·인쇄: 비밀값·가족 정보·경비를 뺀 일정표. 인쇄(PDF 저장), HTML 파일, 공유.
  - 데이터: AI로 고치기(고치기·예약 메일·장소 추가·경고 해결·회고 정리·가격 조사), 비밀값 입력과 다른 기기로 옮기기, JSON·.ics 내보내기, 커밋/불러오기, 커밋 기록·**기기 기록**(고치기 전 상태 최근 10개)에서 되돌리기, 복제해서 새 여행.
  - .ics에는 항공·체크인·교통 마감 외에 준비 마감일과 자동 알림(09:00, 공항 도착 목표는 30분 전 알림)도 들어간다.
- 길찾기: 국내 여행은 카카오맵·네이버지도·구글맵 순(국내 장소 정보는 카카오·네이버가 풍부), 해외 여행은 구글맵만.
- 지우기는 바로 지우고 토스트의 [되돌리기]로 되살린다.

## 데이터 형식 trip/v1

`schema/trip.v1.json`(JSON Schema)이 형식 문서다. 앱의 검사기(`assets/validate.js`)는 여기에 더해 참조 무결성과 일정 점검까지 본다.

- 여행 하나 = 파일 하나. 장소는 `places`에 한 번만 두고 일정은 `placeId`로 연결.
- 시각은 `meta.timezone` 현지 시각(`YYYY-MM-DDTHH:MM`). 날짜 `YYYY-MM-DD`, 시간 `HH:MM`.
- 비밀값은 본문에 `{{secret:키}}`, `secrets`에는 키와 이름만. 값은 기기 localStorage에만.
- 교통 마감 `deadlines[]`: `after`(그 교통 도착 + `bufferMin` > `at`이면 경고), `before`(`at` + `bufferMin` > 그 교통 출발이면 경고).
- 운영시간 `hours`: `default`, 요일별 `mon..sun`, `lastEntry`, `closed`(요일 배열), `note`.
- 가져오기 전용 키(저장 전에 처리, 파일에 남지 않음): `secretValues`, `_remove`. 부분 JSON은 기존 여행에 병합(배열은 id 기준 upsert, days는 date 기준, 항목 안의 객체는 깊게 병합). 데이터셋 장소를 고치는 부분 JSON(예: 가격 조사)은 먼저 여행 장소로 복사한 뒤 합친다.
- 추가 필드: 일정 `done`·`skipped`·`fixed`, 날짜 `journal`, 장소 `prices`·`pass.surchargePrices`, 교통 `checkinOpensH`·`airportBufferMin`, 여행 `documents`.
- 검사기는 다른 장소들에서 150km 넘게 떨어진 좌표와, 앞뒤 장소 직선거리와 크게 다른 이동 km도 경고한다(AI가 잘못 넣은 값 잡기).
- 묶음 `bundle/v1`: `{ "schema": "bundle/v1", "trips": [], "datasets": [] }` — 여러 파일을 한 번에 가져온다(전체 백업도 이 형식).

## AI로 데이터 만들기

[새 여행] → [프롬프트 복사](규칙 + 가족 프로필 요약 + 빈 양식) → 여행을 상의하던 AI 채팅 끝에 붙여넣기 → AI가 준 JSON을 붙여넣고 [검사] → 오류/경고/요약/비밀값 → 미리보기 → [저장] → [커밋].
프롬프트 원문은 `assets/prompts/*.txt`: Handoff의 5종(새 여행, 기존 여행 고치기, 장소 추가, 예약 메일 정리, 지난 여행 정리)에 경고 해결 요청(점검 결과·가족 규칙 포함), 회고 정리(날짜별 한 줄 기록·완료·건너뜀), 장소 가격 조사(출처 필수)를 더했다.
코드블록 표시·앞뒤 설명·끝 쉼표·스마트 따옴표는 자동으로 걷어내고, 그래도 안 되면 몇째 줄 몇째 글자에서 막혔는지 보여준다.

## 동기화 규칙

- 저장은 기기에 즉시. **자동 동기화**(설정, 기본 켬)면 고친 뒤 40초쯤 지나거나 앱을 내리면 저장소에 올리고, 앱을 열거나 다시 보면 받는다. 끄면 [커밋]으로 올린다.
- **3방향 병합**(`assets/sync.js`): 마지막 커밋본을 기준으로 이 기기와 저장소의 변경을 항목 단위로 합친다. 배열은 `id`(일정·장소 등), `date`(days), `key`(secrets)로 짝을 맞추고, id 없는 배열(패스 이용 기록 등)은 양쪽 추가를 모두 남긴다. 한쪽만 지운 항목은 지우고, 한쪽이 지웠어도 다른 쪽이 고쳤으면 남긴다. 한쪽만 순서를 바꿨으면 그 순서를 따른다.
- 같은 값을 두 기기가 다르게 고쳤을 때만 충돌 시트에서 항목마다 [이 기기]/[저장소]를 고른다. 충돌이 풀릴 때까지 자동 동기화는 멈춘다.
- 올리는 사이 다른 기기가 먼저 올리면(409) 다시 받아 합친 뒤 올린다. 여행 메타가 바뀌면 `trips/index.json`도 갱신. 서류함 파일 올리기·지우기도 이때 처리한다.
- '수정됨'·[되돌리기]의 기준은 마지막 커밋 버전. 합치기 전·충돌 해결 전·AI 적용 전 상태는 기기 기록에 남는다.
- 토큰 만료일(설정에 입력, GitHub가 헤더로 알려주면 자동)이 2주 안이거나 여행 기간과 겹치면 홈에 알린다.

## 가족 규칙 점검

설정 → 가족 프로필의 기준(기본: 하루 고정 외출 2곳, 하루 운전 90분, 한 번 이동 60분, 아이 취침 20:30, 식사·간식 간격 6시간)으로 날마다 점검한다. 선택 일정·건너뛴 일정·숙소 안 일정은 외출로 세지 않는다. 지난 여행에서는 보이지 않는다. 경고는 [AI로 고치기 → 경고 해결 요청] 프롬프트에 그대로 들어간다.

## 구조

```
travel/
├── index.html, manifest.webmanifest, sw.js   # 셸, PWA, 오프라인 캐시
├── assets/
│   ├── app.js        # 상태·라우팅·동기화 엔진·홈·설정·기기 연결 코드
│   ├── sync.js       # 3방향 병합 (DOM 없음, 테스트)
│   ├── docs.js       # 서류함: 저장소 docs/ + 기기 사본 + 대기열
│   ├── v-trip.js     # 오늘·일정·장소·준비·비상
│   ├── v-more.js     # 예약·패스·경비·지도·메모·데이터
│   ├── v-import.js   # 새 여행·가져오기·AI로 고치기·복제
│   ├── validate.js   # 검사기 + 일정 점검
│   ├── importer.js   # 관용 파싱, 부분 병합, _remove, secretValues, 변경 목록
│   ├── model.js, util.js, store.js, github.js, ui.js
│   ├── weather.js (Open-Meteo), map.js (Leaflet), ics.js, prompts.js
│   └── prompts/*.txt
├── schema/trip.v1.json
├── samples/demo.json      # 민감정보 없는 데모
├── vendor/leaflet-1.9.4/  # npm 공식 패키지 그대로(BSD-2), SRI 해시 일치 확인
├── tools/migrate-nhatrang.mjs
└── tests/run.mjs
```

- 빌드 없음. ES 모듈. 외부 스크립트 없음(Leaflet도 저장소에 고정 포함), CSP 메타 태그.
- AI가 만든 문자열은 모두 텍스트 노드로 렌더링한다(innerHTML 미사용, `**굵게**`·`*굵게*`만 변환). 링크는 http·https·tel·nmap·kakaomap만 허용.
- 키가 필요한 API는 쓰지 않는다. 날씨 Open-Meteo, 지도 OpenStreetMap 타일(출처 표기).

## 개발

```sh
python3 -m http.server 8000      # 저장소 루트에서 → http://localhost:8000/travel/
node --test travel/tests/run.mjs # 검사기·3방향 병합·가족 규칙·자동 알림·요금·시간대·.ics·암호화 단위 테스트
```

나트랑 이관(일회성): `node travel/tools/migrate-nhatrang.mjs data.json nhatrang.html out.json` → 결과를 [가져오기].
비밀값 키(`pnr`, `parking`, `car`)는 그대로라, 나트랑 앱을 쓰던 기기에 남은 값을 자동으로 이어받는다.

실기기 확인 항목: iOS Safari·안드로이드 크롬에서 지도 앱 링크(특히 `nmap://`), 위치 권한, 오프라인, 홈 화면 추가.
